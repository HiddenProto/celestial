Transport Controls how proxied requests are sent through the network.

photon — bumblcat's own transport. Server-side TLS via Cloudflare Worker — no WASM SSL, no error 35. Best compatibility. Type: server-side.

epoxy — WebAssembly-based, better site compatibility. Required for multiplayer games with bumblcat rrc — epoxy forwards WebSocket headers (like Origin) to the server, which libcurl does not. Slower. Type: client-side.

libcurl — C-based, faster and more stable. Recommended for most sites. Does not forward custom WebSocket headers — use epoxy for multiplayer games. Type: client-side.

change how the proxy is handled, can lead to sites that were broken to work or lead to sites that were working to break

Proxy Controls how page content is rewritten for proxying.

bumblcat rrc — private BRC fork. Best for multiplayer games: spoofs WebSocket Origin and User-Agent so game servers see the correct origin. Requires epoxy transport. Type: client-side.

scramjet — Mercury Workshop's open-source rewriter. Wider site compatibility. Recommended for general browsing. Type: client-side.

ultraviolet — older rewriter, works with some legacy sites. Type: client-side.

💡 Tip: enable Virtual Entity mode to give the proxy a real browser identity — improves access to Google, YouTube, and other sites that detect proxies.

change which rewriter engine handles proxied pages

Wisp Server The WebSocket relay server that routes proxy traffic.

bumblcat's server — always-on Render server. Easy, no setup. Type: private server.

mercury / anura / nodeppt — free public servers. May show Google CAPTCHA. Type: public server.

local Wisp — your own device. Enter IP and port (e.g. 192.168.1.5 : 58443). Only works on your network. Type: self-hosted.

no Wisp (static) — disables the Wisp relay. Only static content works; most sites will fail. Use if you have a custom transport. Type: none.

custom — any Wisp URL you supply. Type: user-defined.

the server that routes your proxied traffic

Quick Apps & Media Controls how quick apps and media sites are loaded when opened from the new tab page.

static (default) — opens apps directly without the proxy. Works for most accessible sites. Faster.

proxied — routes apps through the selected proxy engine. Use if apps are blocked on your network.
